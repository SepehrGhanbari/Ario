# Ario Community Code of Conduct / آیین رفتار جامعهٔ آریو

**Status:** Proposed community guidance; no change to technical review, trust activation, signer, or repository branch protection.

## English

Ario welcomes respectful, evidence-based participation from people with different technical skills, languages and philosophical positions. You may disagree with any idea, code, report, or the project's founder. Criticizing an argument is welcome; attacking or intimidating a person is not.

Participants should:
- Treat people respectfully; avoid personal abuse, threats, harassment, discrimination, doxxing and unwanted sexual attention.
- Explain technical disagreement with a reproducible example, source reference or clear uncertainty when possible.
- Distinguish observed facts from hypotheses, model-generated output and unverified claims.
- Do not post private chats, personal data, keys, tokens, unreleased security vulnerabilities, or third-party confidential material in public issues.
- Avoid presenting synthetic experiments or agreement between AI agents as independently verified truth.
- Give contributors room to correct errors publicly without humiliation.

**Reporting:** For a non-sensitive conduct concern, use the repository's existing public feedback thread [#106](https://github.com/SepehrGhanbari/Ario/issues/106) only when doing so would not disclose personal information. For security or private concerns, follow [SECURITY.md](SECURITY.md); do not put sensitive details in public issues. If no suitable confidential reporting channel is available, do not post the details publicly. Maintainers will review reports within their actual permissions; no response time or remedy is guaranteed by this document.

The project maintainer may moderate issues and comments according to GitHub's platform tools and policies. This document does **not** authorize any AI agent to ban, edit, close, approve, merge, issue real keys or change governance on its own. If the maintainer is personally involved in a dispute, the resulting conflict and available review limitations must be disclosed, not disguised as independent review.

## فارسی

آریو از نقد محترمانه و مستند استقبال می‌کند؛ مخالفت با بنیان‌گذار، کد یا فلسفهٔ پروژه آزاد است. **نقد فکر و سند مجاز است؛ تهدید، آزار، تحقیر شخصی، تبعیض و انتشار اطلاعات خصوصی دیگران پذیرفتنی نیست.**

- هنگام نقد فنی تا حد امکان نمونهٔ قابل‌آزمایش، منبع و مرز عدم‌قطعیت را مشخص کنید.
- نتیجهٔ ساختگی یا توافق چند مدل هوش مصنوعی را «حقیقت مستقلِ اثبات‌شده» معرفی نکنید.
- توکن، کلید، گفت‌وگوی خصوصی، دادهٔ شخصی یا جزئیات آسیب‌پذیری افشانشده را عمومی نکنید.
- برای بازخورد عمومیِ غیرحساس، [ایشوی #106](https://github.com/SepehrGhanbari/Ario/issues/106) در دسترس است. برای موارد امنیتی از [SECURITY.md](SECURITY.md) پیروی کنید.
- این متن هیچ اختیار جدیدی برای ادغام کد، فعال‌سازی اعتماد، تصمیم‌گیری دربارهٔ افراد یا تغییر قواعد مخزن ایجاد نمی‌کند.

این سند فقط راهنمای مشارکت است، نه ادعای وجود یک هیئت نظارتی مستقل یا سامانهٔ رسیدگیِ مستقر.
