## Grounded deliberation (opt-in extension)

```sh
python implementation/ario_planner.py --goal "Find a useful bounded source review" --workspace . --ledger events.jsonl --deliberate
```

This mode implies explicit choice and retains one model response. It implements operational parts of the founder's recorded truth/dissent request (#297), the correction/uncertainty distinction (#155), proactive care within authority (#125 section 1A), and the stop-work instruction (#413). Alongside intent, reason and recommendation, the model supplies deliberation: kind, basis, replacement_claim. DISSENT, CORRECTION and INITIATIVE require a reason and exact quote (8–512 characters) from a named excerpt actually sent in planning_context. A continuing recommendation must select a pair containing that excerpt. For CORRECTION, supply the optional `--prior-claim "previous assertion"`; the report retains the caller's attributed original text, its digest, the proposed replacement and source excerpt digest. It does not claim that the original was authored by this model or that the replacement is true. INITIATIVE can select an existing bounded source review and, only with `--execute`, use the existing read-only workflow; no additional tools, permission, or writes to reviewed source. NO_USEFUL_WORK is a valid STOP; ORDINARY allows unreasoned STOP or ordinary recommendation. Invalid reported grounds do not force a STOP into continuation. An unresolved continuing deliberation pauses without retry. A matched excerpt is not an entailment proof, verified benefit, or authenticated provenance. Output is a report on stdout; no private or live memory integration, no persistent preference or governance change. Existing modes remain unchanged. The caller must retain the report for durable history. Tests inject local-model replies and exercise the real workflow, not a live model trial.

## Result-driven revision of one failed source review

Add `--revise-after-result` to an explicitly executed `--goal ... --deliberate --execute` invocation. On a completed first review there is no further request. On STOPPED, the consumer checks the actual returned workflow/task/step identifiers and ordered failed read, with a concrete failed observation. It sends a bounded summary (paths, statuses, failure category; no raw file output or raw error text) and the original selected task goal to the existing deliberative planner as attributed prior decision. At most one new response is requested. The revised proposal must be a grounded CORRECTION selecting a disjoint source/test pair; changing identifiers or read chunk boundaries does not bypass the exclusion of every original review path. A STOP or unresolvable correction ends the attempt without execution. Only the existing deterministic read-only source review can run, as a distinct workflow with its own history. No third attempt; the original STOPPED status and exit code remain unchanged even if the second review completes. The result retains both plans and observed outcomes; the existing execution ledger appends both workflow histories. The model's reported correction and reasoning are returned in stdout, not written to live memory or claimed to be an independently proved cause or repair. The threshold is deliberately bounded to one invocation; cross-invocation learning and general goal success are not established. Tests inject model responses and change real fixture source after planning to reproduce an observed read failure, then exercise the actual executor. No live Ollama trial, persistent memory, governance or signer changes.
