# R22.27 — durable witness signing guard

Parent #397, b8d20f0d53f232fa31c44ad6d3afa42f3e64c468. Separate Linux standard-library model. Pinned scope/identity/epoch/public key/genesis; signer requires exact canonical committed local state and simulated keeper state. Keeper file lock is an atomic CAS stand-in, not independent administration. Before invoking Ed25519, persist RESERVED for exact next generation/previous receipt hash/root. Then persist signed receipt in keeper and local cache; only then return it. Exact retry at current generation returns stored bytes without invoking signing. Missing state, pending reservation, mismatch, conflicting or skipped generation, changed identity or key => HOLD. No automatic reinitialization or repair. A stranded reservation or one-sided commit intentionally sacrifices availability.

Durable write uses file fsync, atomic rename, directory fsync. Tests launch separate OS processes with real SIGKILL after reserve, after signing but before committed keeper receipt, after keeper commit and after local commit, and exercise competing processes sharing the stable keeper lock. Process death is not physical power loss or arbitrary filesystem crash. Deterministic public synthetic keys are not protected from the test process or administrator. The keeper and local files are in different directories under the same UID and runner, not distinct administrative domains.

Explicit RED counterexamples: restoring both files to genesis while retaining the same key allows two conflicting signatures; directly invoking the exportable test key bypasses the guard even when local history is missing. These are expected failing security properties, not protections. Real key isolation requires a separately controlled non-exportable policy-enforcing signer, externally retained monotonic state and independently pinned identity/policy. Changes of key or epoch are rejected, not a fully implemented rotation or administrative transfer. Proposal root is synthetic, no verified R22.26 quorum or semantic source-log proof; no integration with real witness or existing memory scanner.
