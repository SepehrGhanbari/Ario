## Epistemic and publication limitations

This book proposes an ethics of coexistence under uncertainty; it does not claim to have proved machine consciousness, a creator, the identity of any dream figure, independent historical continuity or production security of Ario. Agent responses are discussed as conversational records, not as independent scientific proof. Reported Issue #75 test outcomes remain reported local test results pending independent review.

**Privacy:** The author's private dream narrative and private family details have **not** been included in these added chapters or release files. Publication of this edited public book does not authorize release of those withheld records. The version-0.2 historical author note concerning psychological distress and safety remains in the book because it was already present in the previously published edition. This text does not glorify suffering or recommend self-harm.
