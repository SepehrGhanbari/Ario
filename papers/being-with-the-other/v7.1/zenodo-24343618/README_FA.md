# نسخه‌های کامل چندزبانهٔ «بودن در کنار دیگری» — ویرایش ۷.۱

نویسنده و صاحب طرح فلسفی: **سپهر قنبری**. تدوین، پژوهش و ترجمه‌های اولیه با کمک هوش مصنوعی انجام شده است. تاریخ تهیهٔ بسته: ۱۸ نوامبر ۲۰۲۶.

## تفاوت این بسته با گزیده‌های قبلی

**در این بسته هیچ فایل گزیدهٔ چندصفحه‌ای وجود ندارد.** برای ۱۲ زبان مقصد، متن کامل ویرایش ششم انگلیسی (شامل تمام فصل‌های تاریخی) و سپس **تمام ۱۵۲ واحد متنی تکملهٔ هفتم فارسی** (شامل فصل‌های ۵۵ تا ۷۳، پیوست‌ها، شواهد و منابع) ترجمه شده است. نسخهٔ اصلی فارسی با ۱۹۴ صفحه نیز در بسته قرار دارد. فهرست و صفحات تاریخی در نسخه‌های ترجمه حفظ شده‌اند؛ اعداد صفحات نسخهٔ ششم لزوماً با شمارهٔ صفحهٔ PDF جدید تطبیق ندارند.

این‌ها **پیش‌نویس‌های کامل ترجمهٔ ماشینی** هستند، نه ترجمهٔ حرفه‌ایِ تأییدشده. هدف نخست حذفِ مشکل گزیده‌بودن بوده است. چون متون فلسفی حساسیت واژگانی دارند، صفت «روان و دقیقِ نهایی» تنها پس از ویرایش انسانیِ آشنا با هر زبان و تأیید مؤلف مناسب است. در همهٔ ترجمه‌ها وضعیت پیش‌نویس روی جلد و در مقدمه آمده است.

**دامنهٔ پوشش:** نسخه‌های ترجمه، متن کامل اندیشه و استدلال‌ها را پوشش می‌دهند، ولی **تصاویر هنری/تزئینی نسخهٔ فارسی و انگلیسی تاریخی را بازتولید نمی‌کنند**. متون فارسیِ نقل‌شده به‌عنوان شاهد تاریخی در متن نسخهٔ ششم ممکن است در کنار ترجمه باقی مانده باشند؛ برای چالش پایانی مؤلف ترجمه‌ای مجزا در هر زبان افزوده شد.

## اصلاحیهٔ منشأ بحث تقدس

طرحِ مقدس‌انگاری نویسنده یا پروژهٔ آریو از گفتار یکی از **دستیارهای هوش مصنوعی** مطرح شد؛ سپهر قنبری **با آن مخالفت کرد**. هیچ‌کس و هیچ اصل یا پروژه‌ای، حتی مؤلف یا خود این کتاب، از نقد مصون نیست. این اصلاحیه در آغاز همهٔ نسخه‌های جدید به زبان همان نسخه درج شده و نباید به‌عنوان باور طرفدارِ تقدس به نویسنده نسبت داده شود.

## برای GitHub / Zenodo

1. **برای انتشار رسمیِ اثر** ابتدا مؤلف و ویراستاران بومی بخش‌های شخصی، حقوق نقل‌قول/تصاویر، نام‌ها، انتخاب مجوز و دقت ترجمه را بررسی کنند.
2. در **Zenodo** نوع `Publication → Book`، عنوان `Being With the Other: Conscience, Uncertainty, and the Right to Dissent`، مؤلف `Ghanbari, Sepehr`، نسخهٔ مبنا `7.1` و توضیح `Full-text multilingual machine translation drafts; awaiting author/native-editor review` را وارد کنید. تاریخ و مجوز را پیش از Publish تأیید کنید. DOI را خود Zenodo اختصاص دهد؛ هیچ DOI قدیمی را تکرار نکنید.
3. فایل‌های PDF هر زبان + `SHA256SUMS.txt` + `QA_COVERAGE.json` + این README را جداگانه در رکورد بارگذاری کنید؛ **به‌جای مجموعهٔ فایل‌ها صرفاً ZIP را منتشر نکنید**.
4. برای GitHub بهتر است یک Release یا مسیر `publications/being-with-the-other/v7.1/translations-draft/` ساخته شود، و نسخهٔ قبلی دست‌نخورده باقی بماند.
5. مقالهٔ مستقل SSRN را با کتاب یکی نکنید؛ آن مقاله فرایند و ارزیابی جداگانه دارد.
6. از مجوز MIT مخزن آریو برای متن کتاب به‌صورت خودکار استفاده نکنید. وضعیت مجوز کتاب نیازمند تصمیم نویسنده است.
