## Which file should a model use?

Use the **text edition** for source-text inspection when ZIP extraction or Git cloning is unavailable. Use the **full edition** for recoverability and byte verification when a script can parse and Base64-decode its embedded binary content. Neither edition guarantees that an AI model has read the whole file in a single context window; ask the model to disclose the exact files it inspected, its limitations, and the evidence for its conclusions. No scientific, safety, authorial, or security certification is inferred from publication.
